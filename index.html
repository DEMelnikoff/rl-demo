How to Read This Demo

Baseline: All algorithms learn correctly over 50 trials with goal = 🍎 apple. Red rocket leads to apple → all prefer red.

Transition Revaluation: Phase 2 swaps planet→resource links (red now leads to salad). Agent placed directly at planets — no rocket choice. Model-Based adapts immediately (T updates). SR does NOT adapt (M_red/M_green frozen — SR key insight!). Model-Free does not adapt.

Outcome Revaluation: Phase 2 changes goal to 🥗 salad. Agent placed at planets. Model-Based adapts (R updates). SR adapts immediately (w updates — dot(M_green, w) rises). Model-Free does not adapt.

SR Heatmap: Watch rows 0-1 (M_red/M_green) stay frozen during Phase 2 of Transition Revaluation, while rows 2-3 (M_planet) update. This is why SR fails to adapt to transition changes but succeeds at reward changes.
